# ⚡ Enervision – AI Energy Audit System

## 🚀 Overview

Enervision is an AI-powered energy audit system designed to monitor, analyze, and optimize energy consumption using data-driven techniques. The system combines analytics and intelligent insights to identify inefficiencies and improve energy utilization.

---

## 🎯 Key Features

* 📊 AI-based energy consumption analysis
* ⚡ Peak hour detection
* 🔍 Appliance-wise energy breakdown
* 🌱 Carbon footprint tracking
* 📈 Monthly energy reports
* 💡 Smart recommendations for energy optimization

---

## 🛠 Tech Stack

* Python (Data Analysis & Processing)
* React (Frontend Dashboard)
* Vite (Build Tool)
* Tailwind CSS (UI Styling)
* npm (Package Management)

---

## 📊 System Workflow

Data Input → Data Processing → AI Analysis → Visualization → Insights & Recommendations

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/enervision.git
cd enervision
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Run the Project

```bash
npm run dev
```
